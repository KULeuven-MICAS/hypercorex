# Hardware

The hardware moves into this directory at milestone H0.

Until then, it is parked at the repo root and left unchanged: `rtl/`, `tests/`,
`questa/`, `Bender.yml`, `Makefile` and `conftest.py`. There is no `hw` pixi
environment yet, so the parked tests run from a checkout of the tag
`discontinue-old-hypercorex`.

See [`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md), section "HW", for its current
state and the notes kept for H0.
